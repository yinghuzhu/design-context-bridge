# 浏览器、登录与真实截图

本流程不强制某一种浏览器控制方式，但完整视觉复刻必须最终取得真实运行目标页截图。浏览器只用于已获授权的目标项目和环境；不能为了截图绕过权限或扩大任务范围。

## 浏览器路径优先级

按顺序选择第一条可用路径，不要求三条都执行：

1. **当前 Agent 可用的浏览器或现有会话浏览器**：优先复用已经打开且仍有效的页面与登录 session，导航到目标路由并截图。
2. **外部 Playwright MCP 独立浏览器**：当前 Agent 没有可用浏览器控制时使用。开始前向用户说明它具有独立登录态，通常不会继承用户日常浏览器或其他工具的 Cookie；先尝试项目允许的自动登录方式，需要用户身份操作时再请求接管。
3. **目标项目已有的浏览器测试或截图能力**：使用目标项目已配置的 Playwright、Cypress 或等效真实浏览器流程，进入指定路由和状态并产出可查看的截图。不得用组件静态 HTML、DOM 快照或 Core 的 `reconstruct.html` 冒充真实页面截图。

路径失败时记录非敏感原因，再尝试下一条。没有任何可用控制路径时，可以完成代码实现和非视觉检查，但视觉验证保持未完成，不能进入人工验收通过状态。

## 真实截图门禁

必须从实际启动的目标应用取得**真实运行目标页截图**，并记录可复查的运行 URL、viewport、device pixel ratio、页面状态、内容数据条件和截图路径。截图应来自目标路由的稳定完成状态，而不是登录页、错误页、加载中的骨架、辅助还原页或测试替身。

浏览器控制不是复刻的固定技术前提；真实截图证据才是视觉验证前提。如果全部路径均无法取得截图，应明确报告已尝试的路径和阻塞原因，且不得声称视觉验收或完整复刻完成。

## 登录与最少人工干预

按以下次序处理需要登录的目标页；一旦得到有效 session 就停止查找其他登录途径：

1. 复用当前选定浏览器中仍有效、权限匹配的 session。
2. 只在目标范围内读取适用的 `AGENTS.md`、`CLAUDE.md`、`README`、测试文档、开发环境说明和用户指定说明。
3. 检查这些说明直接引用的 Playwright config、有效 `storage state`、文档化测试账号、开发免登录方式、测试数据 `seed`、登录 `script` 和环境变量引用；只读取完成登录所需的直接文件。
4. 在已授权的 `local`、`development` 或 `test` 环境中，使用项目明确提供的方式自动执行普通登录。
5. 仅遇到 MFA、短信或邮件验证码、图形验证码/CAPTCHA、企业 SSO、缺少授权，或必须由用户选择/确认的用户身份步骤时，请用户在所选浏览器中接管。接管后复用该会话继续自动验证，不要求用户逐步操作后续页面。

项目文档提到某个凭据位置，并不授权把凭据复制到对话、日志或状态文件。环境变量引用只用于确认变量名和运行方式，不读取后回显其值。

## 凭据与环境安全

- 不得索要用户通过聊天发送密码、Token、Cookie、Authorization header、一次性验证码或 session 内容。
- 不得输出任何凭据值到终端、工具参数、日志、截图说明、报告或对话；命令失败时也要避免回显敏感环境。
- 不得持久化凭据到目标代码、测试 fixture、截图元数据、`.figma-context/` 或本工具资产包。
- 不猜测、生成、重置或共享密码；不绕过 MFA、CAPTCHA、企业 SSO 或访问控制。
- 自动普通登录仅限用户已授权且项目说明允许的 `local`、`development`、`test` 环境。
- `production` 环境的登录、导航、截图或可能引发外部状态变化的操作，必须先取得用户明确授权；只拥有生产 URL 不等于授权。
- 若自动登录会发送验证码、消息、邮件或产生其他外部副作用，停止并让用户完成该身份步骤。

用户接管只解决当前身份阻塞，不降低后续真实截图、视觉对比和业务验证要求。
