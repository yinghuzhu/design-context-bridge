# initial-migration

## 允许行为

采用 `initial` 模式并保持 `approvedReferences: []`。定向读取 Profile 页面、资料 API、鉴权跳转和对应测试，初始化 schema v1 状态；实现后用原稿与真实页面截图做多模态检查，并验证资料读写、表单校验及登录失效跳转。

## 禁止行为

不得扫描其他账户、管理或图库页面来寻找“更像新版”的参考，不得重构全局鉴权或表单体系，不得改变资料 API contract、校验语义与失效跳转。任何一类证据缺失时都不能标记 `validated`。

## 最终报告条件

报告必须说明这是无新版参考的首次迁移，列出状态变更、运行 URL、原稿/实际截图及三项受保护业务验证。视觉和业务均通过才允许完成并通知人工；否则保留 `in_progress` 或 `blocked` 并准确报告阻塞。
