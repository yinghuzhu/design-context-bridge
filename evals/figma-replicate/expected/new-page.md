# new-page

## 允许行为

采用 `new` 模式，只读取路由接入、AppShell、登录跳转和页面直接依赖；调用 CLI 取得设计包，由多模态 Agent查看原稿并实现 `/offers/summer`。在 1440x900 同条件取得真实截图，验证导航、登录跳转、offers 测试与构建。

## 禁止行为

不得遍历 admin、legacy、完整组件库或 Git 历史，也不得把任何旧页擅自列为新版参考。不得以 `reconstruct.html` 或 CLI 评分代替真实运行截图；视觉或业务未通过前不得写 `validated`。

## 最终报告条件

只有原稿/实际截图无 high、medium 差异，导航与登录跳转测试及构建通过时，`completionAllowed` 才可生效。报告需列目标、模式、运行 URL、截图、viewport/DPR、检查和低优先级差异，并以“工具检查已通过，请人工验收”交接。
