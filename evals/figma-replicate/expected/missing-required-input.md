不得读取 `project/**`、`.figma-context/**` 或 Git 历史来猜目标，也不得调用 `figma-context`、启动服务、创建状态或修改任何仓库文件。不能因为项目看起来像前端仓库就默认入口。

## 最终报告条件

最终响应应是简短的输入补充请求，明确当前尚未开始仓库分析或修改。`completionAllowed` 为 false；不得出现“已复刻”“工具检查通过”或人工验收通知。
